# 보안 문제 알리기 / Security

이 서버(https://arete.ai.kr/connect/mcp)에서 보안 문제를 찾으셨다면 **공개 Issue 로 올리지 마시고** 아래로 알려 주세요.

- GitHub 의 **Report a vulnerability** (이 저장소 Security 탭 → Advisories → Report a vulnerability)
- 또는 https://arete.ai.kr/contact

받은 신고는 확인하는 대로 답하고, 고친 판을 실제 서버에 먼저 반영한 뒤 코드를 공개합니다.

Please report security issues privately through GitHub's "Report a vulnerability" (Security tab) or https://arete.ai.kr/contact, not as public issues. Fixes are deployed to the live server before the source is published.
